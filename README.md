# Mi Proyecto
Una app de recetas para principiantes 🍳

## Tecnologías usadas
- React
- TailwindCSS
- Vite

## Cómo correr el proyecto
1. Clona el repo
2. Ejecuta `npm install`
3. Ejecuta `npm run dev`

## Despliegue automático (GitHub Pages)
Este repositorio incluye un workflow en `.github/workflows/deploy-pages.yml`.

Pasos para publicarlo:
1. En GitHub ve a **Settings > Pages**.
2. En **Build and deployment**, selecciona **GitHub Actions**.
3. Haz push a la rama (`main`, `master` o `work`) y el workflow publicará la web.
4. Revisa la URL publicada en la pestaña **Actions** al terminar el job.
